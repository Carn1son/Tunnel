# Tunnel

Windows client for self-hosted [TrustTunnel](https://github.com/TrustTunnel/TrustTunnel) VPN servers.

## About

- Desktop port of the open-source TrustTunnel client by AdGuard
- Connects only to servers you run yourself
- Traffic looks like regular HTTPS (HTTP/2 or HTTP/3 over TLS)
- Same design family as BoardV and 3DViewer

## Status

- In development, no releases yet
